# Cryptographic Encryption and Simulation Tool

A comprehensive desktop application built with Python and Tkinter for encrypting and decrypting text using various classical and modern cryptographic algorithms.

---

## Features

- **Multiple Algorithms Supported:**
  - Shift (Kaydırma)
  - Affine (Doğrusal)
  - Substitution (Yer Değiştirme)
  - Permutation (Permütasyon)
  - Columnar Transposition / Route (Sayısal Yer Değiştirme / Rota)
  - Zigzag
  - Vigenère
  - Hill Cipher
  - Four-Square Cipher
- **Intuitive GUI:** Easy-to-use graphical interface built with Tkinter.
- **Bilingual Support (Alphabet):** Tailored to handle Turkish alphabet characters seamlessly.

---

## Project Structure

```text
├── sifrele.py      # Encryption tool with graphical interface
└── sifrecozme.py   # Decryption tool with graphical interface
```

---

## Requirements

Make sure you have Python installed along with the required libraries:

- Python 3.x
- `numpy`

You can install the dependencies using pip:
```bash
pip install numpy
```

---

## Usage


1. Run the encryption script:
   ```bash
   python sifrele.py
   ```
2. Run the decryption script:
   ```bash
   python sifrecozme.py
   ```

# Kriptografik Şifreleme ve Simülasyon Aracı

Python ve Tkinter kullanılarak çeşitli klasik ve modern kriptografik algoritmalarla metin şifreleme ve şifre çözme işlemleri yapmak için geliştirilmiş kapsamlı bir masaüstü uygulaması.

---

## Özellikler

- **Desteklenen Algoritmalar:**
  - Kaydırma (Shift)
  - Doğrusal (Affine)
  - Yer Değiştirme (Substitution)
  - Permütasyon (Permutation)
  - Sayısal Yer Değiştirme / Rota (Columnar Transposition / Route)
  - Zigzag
  - Vigenère
  - Hill Şifresi (Hill Cipher)
  - Four-Square Şifresi
- **Kullanıcı Dostu Arayüz:** Tkinter ile oluşturulmuş sezgisel grafik arayüz.
- **Türkçe Alfabe Desteği:** Türkçe alfabedeki karakterleri sorunsuz işleyecek şekilde uyarlanmıştır.
